# Flutter Lab Project

This project is a basic Flutter application developed as part of a lab exercise to understand core Flutter concepts and UI development.

The app demonstrates:

* Building user interfaces using widgets
* Creating layouts with GridView, Forms, and Cards
* Handling user input and validation
* Displaying images from the internet
* Implementing navigation between screens

The project includes:

1. A **Product Catalog Screen** that displays items in a grid with images, names, and prices.
2. A **Registration Form Screen** that collects user information with validation and shows feedback.
3. A **Profile Card Screen** that presents user details using styled cards.
4. **Navigation** between different screens using routes.

This lab helped in understanding how Flutter apps are structured, how widgets are used to build responsive interfaces, and how to manage user interaction and screen transitions effectively.

Overall, the project focuses on learning the fundamentals of Flutter development in a simple and practical way.
